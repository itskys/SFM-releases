# SFM · Super Files Manager —— 发布与反馈

**一个把"可信去重与空间治理"当第一公民的 Windows 文件管理器。**

秒搜是入口，删得放心是留存：SFM 不只是"扫出重复让你自己赌哪个能删"，而是**先分层校验、
逐字节复核、留完整审计、仅回收站可回滚**。

> 这个仓库**只放发布物与反馈**，不含源码。源码仓暂未公开。

---

## ⚠ 内测版，请先读这两条

**1. 这是预发布版本，请勿在唯一一份重要数据上首次试用。**
删除相关的功能有硬性设计约束——**只走回收站，永不永久删除**，且删除前会重核文件身份——
但内测阶段仍请先在可以承受的数据上跑一遍，建立你自己的信任。

**2. 首次运行会看到 SmartScreen「Windows 已保护你的电脑」。**
这不是病毒警报，是**没有代码签名证书**的结果：证书要求私钥存放在硬件中，
中国大陆开发者目前拿不到主流云签名服务（详见下方「关于那个警告」）。
你可以先用下面的 SHA256 校验文件完整性，再决定要不要继续。

**直接下载**（点了就开始下）：

### ⬇ [安装版 SuperFilesManager-0.7.0-setup.exe](https://github.com/itskys/SFM-releases/releases/download/v0.7.0/SuperFilesManager-0.7.0-setup.exe) （46 MB）

每用户安装，**不需要管理员权限**；有开始菜单项与正常的卸载入口。大多数人选这个。

### ⬇ [便携版 SuperFilesManager-0.7.0-portable.zip](https://github.com/itskys/SFM-releases/releases/download/v0.7.0/SuperFilesManager-0.7.0-portable.zip) （65 MB）

解压即用，不写注册表；想随时删干净就用这个。

校验和：[SHA256SUMS](https://github.com/itskys/SFM-releases/releases/download/v0.7.0/SHA256SUMS)　·　
全部版本见 [Releases 页面](https://github.com/itskys/SFM-releases/releases)

**系统要求**：Windows 10 1809（build 17763）或更高的 64 位系统。
低于这个版本装不上——程序依赖的几个系统接口（回收站删除、缩略图、文件属性、媒体预览）
老系统没有，装得上却跑不起来比装不上更糟。

**卸载**：安装版走"设置 → 应用"或开始菜单的卸载项。卸载时会**问你一句**要不要连同设置和
内容索引一起删（索引可以到几十 GB），**默认不删**——万一你只是重装，删掉意味着重扫全盘。

## 关于那个警告

首次运行时 Windows 会拦一下，写着"未知发布者"。点「更多信息」→「仍要运行」即可。

**为什么会这样**：自 2023 年起，公开信任的代码签名证书要求私钥必须存放在符合
FIPS 140-2 Level 2 的硬件中，因此 CA 不再签发可直接下载的证书文件；
而微软的云签名服务（Azure Artifact Signing）的可用地区清单不包含中国。
本项目目前没有购买商业证书。

**还有一点要说清楚**：即使将来买了证书，SmartScreen 的提示也**不会立刻消失**——
它的信誉是靠下载量累积的。所以在相当长一段时间里，校验和才是你真正能依靠的东西。

**怎么校验**（PowerShell，把文件名换成你下载的那个）：

```powershell
Get-FileHash .\SuperFilesManager-0.7.0-setup.exe -Algorithm SHA256
```

把输出的哈希值与 `SHA256SUMS` 里对应那行比对，一致就说明你下到的和这里发布的是同一个文件。

界面上让你愣了一下的地方（那通常意味着设计有问题，不是你的问题）。

## 主要能力

- **可信去重**：分层验证 + 逐字节复核 + 删除前身份重核 + 完整审计 + **仅回收站、永不永久删除**
- **全局内容检索**：搜文件**正文**（PDF / Office / Markdown / 文本 / 代码），覆盖你指定的任意目录。
  首次向导**先给出空间与时间的代价估算再让你决定**索引哪些位置；中文两字词也能搜
- **秒级搜索**：集成 Everything；未装时回退 Windows 搜索或自建索引
- **预览面板**：图片、文本/代码、PDF（可切文本模式选字复制）、Office、压缩包清单；
  Markdown 完整渲染（含数学公式、语法高亮）并可编辑；音视频首帧与规格，可直接播放
- **空间治理**：Treemap 看清磁盘被谁占满、文件夹大小、文件夹对比/同步
- **通用撤销 Ctrl+Z**：移动/重命名/新建可回退，**删除亦可撤销**（从回收站精确还原到原位）
- **文件加密**：给 PDF / Office 设**原生打开口令**——加密后仍是标准 .pdf/.docx，
  Acrobat / Word 自己弹密码，不依赖本软件解密
- 明/暗双主题、中英双语、标签页与双窗格分屏

## 隐私

- **内容索引完全在本机**，不上传任何内容。
- 私密目录可加入**排除清单**（加密存储，查看或编辑需要主密码）。
- 文件被加密、移入隔离区或删除后，其正文会**立刻**从索引中清除。
- 软件本身不做任何遥测。仅有的联网行为是「检查更新」，每天至多一次、可在设置里关闭。
